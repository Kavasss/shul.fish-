# Shul.Fish — интернет-магазин рыбы

Сайт для продажи свежей, копчёной и солёной рыбы с доставкой, базой заказов и админ-панелью.

## Возможности

**Для покупателей**
- Каталог с разделами «Свежая», «Копчёная», «Солёная».
- Корзина (по весу с шагом, например 0,5 кг, или поштучно).
- Количество в наличии покупателю **не показывается**: оно только ограничивает, сколько можно заказать.
  При попытке заказать больше появляется сообщение «Больше заказать сейчас нельзя»; закончившийся товар помечается «Нет в наличии».
- Оформление заказа: доставка курьером (адрес, дата, интервал) или самовывоз, оплата наличными или картой при получении.
- Стоимость доставки, порог бесплатной доставки и минимальная сумма заказа берутся из настроек.

**Админ-панель** (`/admin`)
- Заказы: список с фильтром по статусам, карточка заказа, смена статуса, заметки, выгрузка в Excel (CSV).
  При отмене заказа товар автоматически возвращается в наличие.
- Товары: добавление, редактирование, удаление, загрузка фото, скрытие с сайта.
- Наличие редактируется прямо в таблице — изменения сохраняются сразу.
- Настройки: стоимость доставки, бесплатная доставка от суммы, минимальный заказ, адрес самовывоза, интервалы доставки, телефон.
- Необязательно: уведомления о новых заказах в Telegram.

## Технологии

- Node.js 22.13+ и Express.
- База данных SQLite (встроенный модуль `node:sqlite`), файл `data/shop.db` создаётся автоматически.
- Фронтенд без сборки: HTML, CSS, JavaScript в папке `public/`.

## Запуск

```bash
npm install
cp .env.example .env     # затем заполните .env своими значениями
npm start
```

Сайт откроется на http://localhost:3000, админка — на http://localhost:3000/admin.

В `.env` обязательно задайте:
- `ADMIN_PASSWORD` — пароль для админки (без него вход отключён);
- `SESSION_SECRET` — длинная случайная строка:
  `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.

При работе по HTTPS поставьте `COOKIE_SECURE=1`.

## Что не попадает в репозиторий

В `.gitignore` исключены:
- `.env` — логин, пароль администратора, секреты, токен Telegram;
- `data/` — база данных с заказами и персональными данными клиентов;
- `uploads/` — загруженные фото товаров.

В репозитории хранится только код и пример настроек `.env.example` без реальных значений.
Делайте резервные копии папок `data/` и `uploads/` на сервере.

## Структура

```
server.js        — сервер и API (каталог, корзина, заказы, админка)
db.js            — схема базы данных и настройки по умолчанию
public/          — витрина (index.html, app.js) и админка (admin.html, admin.js)
.env.example     — пример настроек
```
